What If the Output Is a Label?

Last lectures: predict a number (price). Today: predict a category. A clinic measures tumor size and records the diagnosis:

Binary classification The target is \(y \in \{0, 1\}\): benign or malignant, spam or not, fraud or not. We want \(P(y = 1)\) as a function of \(x\).

Can We Just Fit a Line?

The line predicts values below 0 and above 1, and one far-away, already-obvious case drags it (dashed: before). The sigmoid stays sensible: a correctly classified point contributes almost no gradient.

The Sigmoid Function

\( \sigma(z) = \dfrac{1}{1 + e^{-z}} \)
Squashing Any real number becomes a value in \((0, 1)\): readable as a probability.
Self-derivative \( \sigma'(z) = \sigma(z)\,(1 - \sigma(z)) \): the derivative comes free. It will cancel beautifully in the gradient.

\(\sigma(\theta_0 + \theta_1 x)\): \(\theta_0\) slides the transition, \(\theta_1\) sharpens it.

The Logistic Regression Model

\( P(y = 1 \mid x;\, \theta) = \sigma(\theta^\top x) = \dfrac{1}{1 + e^{-\theta^\top x}} \)

Both cases in one line (check \(y=1\) and \(y=0\)):

\( P(y \mid x;\, \theta) = \underbrace{\sigma(\theta^\top x)^{\,y}}_{\text{on when } y=1} \cdot \underbrace{(1 - \sigma(\theta^\top x))^{\,1-y}}_{\text{on when } y=0} \)

Still a linear model at heart: the linearity lives inside \(\theta^\top x\). The sigmoid only translates that score into a probability.

The open question Squared error worked for regression. Does it work here?

Squared Error Meets the Sigmoid

The loss as a function of \(\theta_1\) on the tumor data. Squared error saturates into flat plateaus where the gradient dies; cross-entropy stays a clean bowl.

The Loss Probability Chooses

Same move as last lecture: assume the model, ask which \(\theta\) makes the data most likely.

\( \displaystyle L(\theta) = \prod_{i=1}^{m} \sigma(\theta^\top x^{(i)})^{\,y^{(i)}} (1 - \sigma(\theta^\top x^{(i)}))^{\,1-y^{(i)}} \)
\( \displaystyle \ell(\theta) = \sum_{i=1}^{m} \left[ y^{(i)} \log \sigma(\theta^\top x^{(i)}) + (1 - y^{(i)}) \log (1 - \sigma(\theta^\top x^{(i)})) \right] \)

next: flip the sign, average, and meet the loss

Binary cross-entropy

\( \displaystyle J(\theta) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log \sigma(\theta^\top x^{(i)}) + (1 - y^{(i)}) \log(1 - \sigma(\theta^\top x^{(i)})) \right] \)
Reading it Only one term is active per example. Confident and right: loss near 0. Confident and wrong: \(-\log(p)\) explodes.
Why it wins Convex in \(\theta\), no dead plateaus, and it is exactly maximum likelihood for the Bernoulli model.

The Gradient Is an Old Friend

Differentiate \(J(\theta)\); the sigmoid's self-derivative cancels the log's denominator:

Gradient \( \displaystyle \frac{\partial J}{\partial \theta_j} = \frac{1}{m} \sum_{i=1}^{m} \left( \sigma(\theta^\top x^{(i)}) - y^{(i)} \right) x_j^{(i)} \)
Deja vu Identical in form to linear regression's gradient: (prediction error) times (input). Different model, different loss, same shape of update. This is not a coincidence (it is the GLM story, coming in the MLE lecture).

So training is unchanged: \( \theta := \theta - \frac{\alpha}{m} X^\top (\sigma(X\theta) - y) \).

The Geometry of the Boundary

Where Predict 1 when \(P \ge \tfrac12\), i.e. when \(\theta^\top x \ge 0\). The boundary is the line (hyperplane) \(\theta^\top x = 0\).
Orientation \((\theta_1, \dots, \theta_d)\) is the normal vector: it points toward the predicted-positive side. \(\theta_0\) shifts the line off the origin.
Confidence Distance from the boundary sets confidence: \(P\) approaches 0 or 1 as \(\theta^\top x\) grows in magnitude, and equals \(\tfrac12\) on the line.
Logistic regression can only draw straight boundaries. Remember that; it becomes the cliffhanger of this lecture.

Logistic Regression in Twelve Lines


import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

X = np.c_[np.ones(len(x1)), x1, x2]   # n x 3: bias + two features
theta = np.zeros(3)
alpha = 0.5

for t in range(2000):                 # batch gradient descent
    p = sigmoid(X @ theta)            # predicted probabilities
    theta -= alpha / len(y) * (X.T @ (p - y))

print(theta)                          # boundary: theta . x = 0

Line 12 is the whole lecture: (prediction error) times (input), averaged. Swap the sigmoid for the identity and this is last week's linear regression code.

Summary

The model
\( P(y{=}1 \mid x) = \sigma(\theta^\top x) \): a linear score squashed to a probability.
The loss
Binary cross-entropy: maximum likelihood for Bernoulli labels, convex, no dead plateaus.
The update
\( \theta := \theta - \frac{\alpha}{m} X^\top(\sigma(X\theta) - y) \): error times input, again.
The caveats
Boundaries are straight; accuracy misleads on imbalanced data; pick the threshold for the cost you care about.
