The Hypothesis

Given the data, find a function \(h_\theta\), the hypothesis, that predicts outputs from inputs:

\(x\) \(h_\theta\)⟶ \(\hat{y}\)
Model class Which function? Linear, polynomial, a neural network? Choosing the family of functions is the first decision.
Parameters Within a class, \(\theta\) selects one specific function. Learning is choosing \(\theta\) from data.

Which Function Should We Choose?

A higher-degree polynomial fits the training points better. Is it a better model? (Lecture 5: generalization)

The Linear Hypothesis

\( h_\theta(x) = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \dots + \theta_d x_d \)

With the convention \(x_0 = 1\), this is a single inner product:

The linear model \( h_\theta(x) = \theta^\top x, \qquad \theta \in \mathbb{R}^{d+1} \)

\( h_\theta(x) = \underbrace{[\theta_0, \theta_1, \dots, \theta_d]}_{\text{unknown parameters}} \cdot \underbrace{[1, x_1, \dots, x_d]}_{\text{input features}} \)

Intercept \(\theta_0\) ("bias") is the prediction when all inputs are zero.
Sensitivity \(\theta_j\) is how much \(\hat y\) changes per unit of \(x_j\).

MSE:

Each error contributes the area of a square. The readout is the mean squared error (MSE): the average of those areas.

The Cost Function

Make "best fit" precise. For each example, the residual is \( h_\theta(x^{(i)}) - y^{(i)} \).

\( \displaystyle J(\theta) = \frac{1}{2} \sum_{i=1}^{n} \left( h_\theta(x^{(i)}) - y^{(i)} \right)^2 \)
Why square? Penalizes big misses, treats positive and negative errors alike, and is smooth, so we can use calculus.
Why one half? Pure convenience: it cancels when we differentiate.

Learning becomes an optimization problem: \( \hat\theta = \arg\min_\theta J(\theta) \).

Gradient Descent

Can't see the whole landscape? Feel the slope under your feet and walk downhill.

Update rule while not converged:
\( \quad \theta_j := \theta_j - \alpha \, \dfrac{\partial J}{\partial \theta_j} \)
Direction \(\partial J / \partial \theta_j\) points uphill, so we step against it.
Learning rate \(\alpha\) sets the step size: the most important knob in all of ML.

next: the gradient, worked out by hand

Computing the Gradient

For one example \((x, y)\) (drop the sum for a moment):

\( \displaystyle \frac{\partial}{\partial \theta_j} \tfrac{1}{2}\big(h_\theta(x) - y\big)^2 = \big(h_\theta(x) - y\big) \cdot \frac{\partial}{\partial \theta_j} h_\theta(x) \)

\( \displaystyle \frac{\partial}{\partial \theta_j} h_\theta(x) = \frac{\partial}{\partial \theta_j} \big( \theta_0 x_0 + \dots + \theta_d x_d \big) = x_j \)

LMS update \( \displaystyle \frac{\partial J}{\partial \theta_j} = \big(h_\theta(x) - y\big)\, x_j \qquad \theta_j := \theta_j - \alpha \big(h_\theta(x) - y\big)\, x_j \)

This per-example update is the LMS rule (Widrow–Hoff, 1960).

Gradient Descent in Ten Lines

import numpy as np

X = np.c_[np.ones(len(x)), x]      # n x 2: prepend column of ones
theta = np.zeros(2)                # start anywhere

def grad(theta):                   # grad J = X.T @ (X @ theta - y)
    return X.T @ (X @ theta - y)

alpha = 0.01                       # learning rate

for t in range(200):               # batch gradient descent
    theta -= alpha * grad(theta)

print(theta)                       # close to least-squares solution

Batch GD uses all examples per step. SGD swaps grad for a single random example: cheaper steps, noisier path, same destination (on average).

Can We Skip the Iteration?

Stack the data into a matrix, one example per row:

\( X = \begin{bmatrix} \rule[.5ex]{1.3em}{0.4pt}\, (x^{(1)})^\top \,\rule[.5ex]{1.3em}{0.4pt} \\ \vdots \\ \rule[.5ex]{1.3em}{0.4pt}\, (x^{(n)})^\top \,\rule[.5ex]{1.1em}{0.3pt} \end{bmatrix}, \quad \mathbf{y} = \begin{bmatrix} y^{(1)} \\ \vdots \\ y^{(n)} \end{bmatrix}, \quad J(\theta) = \tfrac{1}{2} \lVert X\theta - y \rVert^2 \)

Set \(\nabla_\theta J = X^\top (X\theta - \mathbf{y}) = 0\) and solve:

Normal equations \( \hat\theta = (X^\top X)^{-1} X^\top \mathbf{y} \)

the normal equations: the answer in one line of algebra

Gradient Descent vs. Normal Equations

Normal equations
  • Exact: no \(\alpha\), no iterations
  • Needs \((X^\top X)^{-1}\): \(O(d^3)\)
  • Fine for \(d\) up to a few thousand
Gradient descent
  • Iterative, needs \(\alpha\)
  • Each step \(O(nd)\), scales to huge \(d\)
  • The only option for neural networks
Takeaway Linear regression is the rare case with a closed form. Everything else in this course descends a gradient.

Why Least Squares? A Probabilistic View

Assume outputs are the model plus Gaussian noise:

Noise model \( y^{(i)} = \theta^\top x^{(i)} + \varepsilon^{(i)}, \qquad \varepsilon^{(i)} \sim \mathcal{N}(0, \sigma^2) \ \text{ i.i.d.} \)

Then each observation is Gaussian around the line, and the likelihood of the dataset is

\( \displaystyle L(\theta) = \prod_{i=1}^{n} \frac{1}{\sqrt{2\pi}\,\sigma} \exp\!\left( - \frac{ ( y^{(i)} - \theta^\top x^{(i)} )^2 }{ 2\sigma^2 } \right) \)

Least squares is maximum likelihood under Gaussian noise

Maximize the log-likelihood (products become sums):

\( \displaystyle \log L(\theta) = n \log\frac{1}{\sqrt{2\pi}\sigma} \; - \; \frac{1}{\sigma^2} \cdot \underbrace{\tfrac{1}{2} \sum_{i=1}^n ( y^{(i)} - \theta^\top x^{(i)} )^2}_{J(\theta)} \)

Maximizing \(\log L\) is the same as minimizing \(J(\theta)\): the noise model chooses the loss.

Different noise, different loss: Laplacian noise gives the absolute error (L1), robust to outliers. The loss function is a modeling assumption, not a law.

Why not interpolate all the points?

A degree-19 polynomial passes through every training point. Zero training error!

Summary

The model
\( h_\theta(x) = \theta^\top x \): linear in parameters, the foundation everything else builds on.
The objective
\( J(\theta) = \tfrac12 \sum_i (h_\theta(x^{(i)}) - y^{(i)})^2 \): the squared error, which is Gaussian maximum likelihood.
Two solvers
Normal equations \((X^\top X)^{-1} X^\top \mathbf{y}\) when small; gradient descent \( \theta := \theta - \alpha \nabla J \) at scale.
The knob
\(\alpha\) too big diverges, too small crawls. You watched both happen.
