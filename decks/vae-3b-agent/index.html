Variational Autoencoders (VAEs)

A powerful framework for learning probabilistic latent representations.

What is an Autoencoder?

The basic components
  • An autoencoder consists of two main parts: the encoder and the decoder.
$$\text{Encoder}: x \rightarrow z_x$$
  • The encoder takes an input \(x\) and maps it to a latent space vector \(z_x\).
  • Mathematically, this is represented as \(\text{Encoder}: x \rightarrow z_x\).
$$\text{Decoder}: z_x \rightarrow y$$
  • The decoder takes the latent space vector \(z_x\) and maps it back to the original input space \(y\).
  • Mathematically, this is represented as \(\text{Decoder}: z_x \rightarrow y\).
$$\text{Latent space vector } z_{x}$$
  • The latent space vector \(z_{x}\) is a representation of the input data, and it has some properties:
  • It is generally lower-dimensional than the original input.
  • It can capture the essential information in the data.

The Latent Space

The setup
  • The latent space \( z_x \) is a continuous vector that represents the data in a lower-dimensional space.
  • Each element of \( z_x \) captures some aspect of the original data distribution, but does so in a way that maintains the overall structure and relationships among the data points.
  • We make the latent space probabilistic to capture uncertainty and variability in the data.
$$z_x \in \mathcal{Z}, \; |z_x| < \infty$$

Reconstruction Loss

The reconstruction loss
  • The reconstruction loss quantifies how well the decoder \(g(z)\) can reproduce the original input \(x\) given a latent vector \(z\).
  • It is defined as:
$$\text{Rec}(y, x) = D(y, g(z_x))$$
  • The choice of \(D(y, g(z_x))\) determines the type of reconstruction loss used.
$$D(y, g(z_x)) = -\int_{y} p(y|z_x) \log(p(y|x)) dy$$
  • The integral is taken over the entire probability distribution of \(y\) given \(x\).
  • The term \(\log(p(y|x))\) measures how well the decoder can reconstruct \(y\) from \(x\).

Why Make the Latent Space Probabilistic?

Making the latent space probabilistic
  • We make the latent space probabilistic to introduce randomness and variability. This allows for more flexibility in modeling complex data patterns.
  • Probabilistic Latent Space: \( p(z|x) \)
  • Each point in the latent space represents a possible configuration of the data. This makes it easier to capture uncertainty and variability in the data distribution.
$$p(z_x|x)$$

The KL Divergence

The role of KLD in VAEs
  • KL Divergence is a measure of the difference between two probability distributions.
  • In VAEs, it quantifies the difference between the true distribution \(p(z|x)\) and the approximate posterior \(q(z_x|x)\).
$$\mathcal{L}_\text{KL}(p(z_x|x), q(z_x|x)) = -\int_{z_x} p(z_x|x) \log(\frac{q(z_x|x)}{p(z_x|x)}) dz_x$$

The reparameterization trick

Making the latent space probabilistic
  • We use a probabilistic model for the latent space, \(q(z|x)\), to capture uncertainty.
  • The reparameterization trick allows us to sample from this distribution efficiently without explicitly computing it.
\begin{align*} &q(z|x) = \mathcal{N}(\mu, \sigma^2),\\ &z = \mu + \sqrt{\sigma^2} \cdot \epsilon, \; \epsilon \sim \mathcal{N}(0, 1) \end{align*}
  • Define every symbol: \(q\), \(z\), \(\mu\), \(\sigma\), \(\epsilon\).

Derivation of the ELBO

$$\mathcal{L}(p(z_x|x), q(z_x|x)) = \text{Rec}(y, x) + \mathcal{L}_\text{KL}(q(z_x|x), p(z_x|x))$$
